# LocalAPI website

Public site and downloads for **LocalAPI**, a simple, local API client for macOS.

- Site: https://bydamiano.github.io/localapi-site/
- Downloads: [Releases](https://github.com/bydamiano/localapi-site/releases)

Static HTML/CSS/JS served by GitHub Pages from the `main` branch. The download page reads the
latest release of this repository through GitHub's API. Releases are published from the app's
source repository with `scripts/publish-site-release.sh vX.Y.Z`.
