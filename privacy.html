Privacy

Short version: LocalAPI has no account, no analytics and no servers. Your data stays on your Mac.

The app

  • Your data is local. Collections, requests, variables, history and API tokens are saved only on your Mac, in ~/Library/Application Support/LocalAPI/data.
  • Requests go straight to your APIs. When you press Send, the request goes from your Mac to the API you chose. It never passes through any server of ours.
  • No tracking. The app collects no analytics, usage statistics or crash reports, and has no account or sign-in. Its fonts and everything else it needs are inside the app, so it works offline too.
  • Sharing is your choice. "Export JSON file" creates a file you decide to send. It never contains tokens.
  • Deleting your data is as simple as deleting the folder above, or the app itself.

This website

  • It is a static site hosted on GitHub Pages, and the downloads are served from GitHub Releases. GitHub may keep technical logs such as IP addresses, under the GitHub Privacy Statement.
  • The download page asks GitHub's public API for the latest version.
  • Fonts are served from this site; no third-party font or analytics services are used.
  • There are no cookies, analytics or trackers of ours.
